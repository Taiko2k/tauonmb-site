## Playback

| Shortcut | Action |
| --- | --- |
| `Space` | Play/pause |
| `Enter` | Play the selected track |
| `-` / `=` | Seek backward/forward |
| `Shift` + `Left` / `Right` | Previous/next track |
| `Home` | Restart the track |
| `End` | Next track |
| `,` | Toggle repeat |
| `.` | Toggle shuffle |
| `;` | Random track |
| `Alt` + `;` | Random album |
| `/` | Random track, starting at a random point |
| `Shift` + `/` | Revert to the previous track, where you left it |
| `Ctrl` + `Up` / `Down` | Volume up/down |
| `Ctrl` + `M` | Mute |

## Navigation

| Shortcut | Action |
| --- | --- |
| `Left` / `Right` | Switch playlists |
| `Ctrl` + `1` … `9` | Go to playlist 1 to 9 |
| `Up` / `Down` | Move the selection |
| `Shift` + `Up` / `Down` | Extend the selection |
| `Page Up` / `Page Down` | Scroll a page |
| `Shift` + `Home` / `End` | Go to the top/bottom of the playlist |
| `'` | Show the playing track |
| `Ctrl` + `'` | Show the previously played track |
| `F4` | Find the playing artist in the playlist |

## Search

| Shortcut | Action |
| --- | --- |
| Start typing | [Global search](/manual/search/) |
| `Ctrl` + `G` | Global search |
| `Ctrl` + `F` or `\` | Find in the current playlist |

## Tracks and playlists

| Shortcut | Action |
| --- | --- |
| `Ctrl` + `A` | Select all |
| `Ctrl` + `C` / `X` / `V` | Copy, cut and paste tracks |
| `Delete` | Remove the selected tracks from the playlist (files aren't deleted) |
| `Ctrl` + `Z` | Undo: restores deleted playlists, removed tracks and sorting changes |
| `Ctrl` + `L` | Love/unlove the selected track |
| `Ctrl` + `Shift` + `L` | Love/unlove the playing track |
| `Alt` + `Q` | Add the selected track to the queue |
| `Alt` + `Shift` + `Q` | Clear the queue |
| `Ctrl` + `I` | Track info for the selected track |
| `Ctrl` + `P` | Track info for the playing track |
| `Ctrl` + `T` | New playlist |
| `Ctrl` + `R` or `F2` | Rename the current playlist |
| `Ctrl` + `W` | Delete the current playlist |
| `Ctrl` + `Shift` + `W` | Delete the current playlist, even if it's locked |
| `Ctrl` + `E` | Open the [smart playlist](/manual/generators/) editor |
| `Ctrl` + `Shift` + `E` | New smart playlist |
| `Alt` + `R` | Regenerate the playlist |
| `F1` | Toggle album headings for the playlist |
| `Ctrl` + `Shift` + `P` | Transfer play counts from a copied track (see [Tips & Tricks](/manual/tips-tricks/#transfer-play-counts-to-another-track)) |

## Customising shortcuts

Shortcuts are defined in the `input.txt` file in Tauon's data folder.

<Steps>
1. Open **Settings › System › Files** and click **Open keymap file**.
2. Edit the file. Each line is an action name, a key, and up to two modifiers (`Shift`, `Ctrl` or `Alt`). For example, `toggle-gallery G Alt`.
3. Restart Tauon.
</Steps>

Some actions have no key by default and can be bound here, including `play`, `pause`, `stop`, `toggle-gallery`, `toggle-right-panel` and `toggle-columns`. `MB4` and `MB5` (mouse back and forward) can be used as keys.
