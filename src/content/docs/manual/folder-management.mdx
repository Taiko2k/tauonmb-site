## Modify Folder

The **Folder Modification** box renames, cleans up or removes an album's folder on disk. Open it either way:

- Right-click a track and choose **Meta… › Modify Folder…**
- Right-click an album heading and choose **Modify Folder…**

The box shows the folder's current path and a preview of the new name.

| Button | What it does |
| --- | --- |
| **Rename** | Renames the folder using the template you enter. |
| **Default** | Resets the template to the built-in default. Shown when you've changed it. |
| **Trash** | Moves the folder to the system trash. Hold `Shift` to change it to **Delete**, which deletes the folder permanently. |
| **Raise** | Shown when the parent folder contains nothing else. Moves the folder up a level and removes the empty parent. |
| **Clean** | Shown when the folder contains clutter. Deletes system files such as `desktop.ini`, `Thumbs.db`, Windows Media Player thumbnails, `.DS_Store` and `__MACOSX`. |

:::caution
These buttons change files on disk. There are some safety checks, but avoid using them on files you can't afford to lose.
:::

The same menus have **Rename Tracks…**, which renames the track files in the album using a template.

## Folder relocate

**Move Playing Folder Here** moves the playing album's folder to another place in your music library.

1. Start playing a track from the album you want to move.
2. Show the [folder navigator](/manual/folder-navigator/) in the left panel.
3. Right-click the destination folder and choose **Move Playing Folder Here**.

The album is placed in a sub-folder named after the artist, which is created if needed. If the destination folder already has the artist's name, the album goes straight into it.

:::tip
Choose **Lock Panel** in the folder navigator's menu to keep it showing one playlist. You can then browse a different playlist and move albums into the locked one.
:::

:::caution
This moves files on disk, with no confirmation. The **entire** source folder is moved, so make sure it only contains files that belong to the album.
:::
