## Set up a server

If you don't have a [Jellyfin](https://jellyfin.org/) server yet, you can try one on Linux with the [Jellyfin Server Flatpak](https://flathub.org/apps/org.jellyfin.JellyfinServer). For Windows and macOS, see [Jellyfin Downloads](https://jellyfin.org/downloads/).

:::tip
If you use the Flatpak server, use Flatseal to give it access to your music folder.
:::

## Import your library

<Steps>
1. Make sure your server is set up, running and reachable from your computer.
2. In Tauon, go to **Settings › Connect** and click the **Jellyfin** tile.
3. Fill in **Username**, **Password** and **Server URL**. Include the port number, which is usually `8096`, for example `http://192.168.1.20:8096`.
4. Click **Test connectivity** to check that Tauon can connect.
5. Click **Import music**. Progress is shown by the activity indicator at the top right. This can take a while for a large library.
</Steps>

## Your library playlist

The import creates a playlist called "Jellyfin Collection". This is your main Jellyfin library playlist. Keep it, even if you make other playlists from it.

When music is added to your server, right-click the playlist's tab and choose **Regenerate** to update it.

## Favourites

When you **love** a track in Tauon, it's marked as a favourite in Jellyfin straight away. Changes made on the server show up in Tauon when you regenerate the library playlist.

## Lyrics

Tauon shows lyrics stored on your Jellyfin server.

## Playlists

To import all your Jellyfin playlists at once, click **Import playlists** in the Jellyfin settings. Import your music first.

To import a single playlist:

<Steps>
1. In the Jellyfin web interface, open the playlist and copy its ID from the address bar:
   ![Screenshot of the Jellyfin web interface with the playlist ID highlighted in the URL](https://user-images.githubusercontent.com/17271572/189612492-ceeaf36c-b635-41df-866f-022bf0ecbb62.png)
2. In Tauon, press `Ctrl` + `Shift` + `E` to make a new [smart playlist](/manual/generators/).
3. In **Take**, choose **+ › Services › Jellyfin playlist…** and paste the ID.
4. Choose **Done**. To fetch the playlist again later, right-click its tab and choose **Regenerate**.
</Steps>

### Syncing playlists

Playlists sync manually:

- If the playlist changed on the server, right-click its tab in Tauon and choose **Regenerate**.
- If you changed it in Tauon, right-click its tab and choose **Upload**.

:::note
**Upload** only sends Jellyfin tracks. Any local tracks in the playlist are left out.
:::

Other settings, such as **Allow local scrobbling** and the network cache, work the same as for [other network sources](/manual/network-sources/).
