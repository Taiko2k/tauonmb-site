## Find the data folder

To open Tauon's data folder, go to **Settings › System › Files** and click **Open data folder**. The usual locations are:

| Platform | Path |
| --- | --- |
| Linux | `~/.local/share/TauonMusicBox` |
| Flatpak | `~/.var/app/com.github.taiko2k.tauonmb/data/TauonMusicBox` |
| macOS | `~/.local/share/TauonMusicBox` |
| Windows | `C:\Users\<user>\AppData\Local\TauonMusicBox` |
| Portable | `user-data`, next to the program |

## What's in it

| File or folder | Contains |
| --- | --- |
| `state.p` | Your playlists, the track database and most settings |
| `star.p` | Play counts, loves and track ratings, kept separately from the main database |
| `album-star.p` | Album ratings |
| `tauon.conf` | Settings, including advanced options not in the Settings window |
| `input.txt` | [Keyboard shortcuts](/manual/keyboard-shortcuts/#customising-shortcuts) |
| `custom_layouts.json` | Your [custom layouts](/manual/layouts/#custom-layouts) |
| `theme/` | Your [themes](/manual/themes/) |
| `artist-pictures/` | Artist pictures |
| `presets/` | [MilkDrop](/manual/milkdrop/) presets |

Files ending in `.backup` are automatic backup copies.

:::tip
To back up Tauon or move it to a new computer, copy the whole data folder. If you only want to keep play counts, loves and ratings, copy `star.p` and `album-star.p`.
:::

## Resetting Tauon

### Partial reset

With Tauon closed, delete `state.p` and `state.p.backup`, and optionally `tauon.conf`. This removes all playlists and resets most settings, but keeps play counts, loves and ratings.

### Full reset

With Tauon closed, delete everything in the data folder. All your Tauon data is lost unless you've backed it up.

## How play counts are tracked

Play counts, loves and ratings in `star.p` are matched to tracks by **file name**, **artist** and **title**.

So to keep them, don't rename files outside of Tauon. If you change tags with another program, right-click the tracks and choose **Meta… › Rescan Tags** (or **Rescan Tags** on an album heading). Tauon reads the new tags and carries the play counts over. Tags edited with Tauon's own [tag editor](/manual/tag-editor/) are handled automatically.

## Recovering play counts for an album

If an album has lost its play counts, for example after you renamed its files, hold `Shift`, right-click the album heading and choose **Vacuum Playtimes**. This collects play counts from any track in the database with the same artist and title, ignoring the file name.
