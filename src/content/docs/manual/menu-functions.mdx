---
title: Menu Functions
description: Where to find common actions in Tauon's menus
---

Most of Tauon's features are in right-click menus. This page covers the main ones. Some items only appear while you hold `Shift`. These are marked with ⇧.

:::tip
Can't find something? Search for it in **Settings**: the search also covers menu items and tells you where to right-click.
:::

## Main menu

Click the record icon in the top-left corner.

| Item | Details |
| --- | --- |
| **New Playlist** | Creates an empty playlist. |
| **Import Music Folder** | Creates a "Music" playlist from your system Music folder. |
| **Settings** | Opens [Settings](/manual/settings/). |
| **Database…** | Library maintenance tools (see below). |
| **Chromecast…** | [Cast](/manual/chromecast/) to a device on your network. |
| **Scrobbling is Active** | Shown while [scrobbling](/manual/scrobbling/) is on. Click to pause it. |
| **Online Manual** | Opens this website. |
| **Show Release Notes** | Shows what's new in this version. |
| **Exit** | Closes Tauon. |

### Database…

| Item | Details |
| --- | --- |
| **Export as CSV** | Exports the track database to `DatabaseExport.csv` in the data folder. |
| **Reload All Folders** | Re-imports the folders of every playlist, picking up new music. |
| **Play History to Playlist** | Makes a playlist of recently played tracks (up to 250). |
| **Reset Image Cache** | Clears cached thumbnails, so updated artwork shows in the gallery. Also lets Tauon retry artist pictures that weren't found. |
| **Clear Artist Cache** | Deletes downloaded artist pictures and biographies, including pictures in `artist-pictures`. |
| **Remove Network Tracks** | Removes all tracks imported from servers such as PLEX, Subsonic and Jellyfin. |
| **Remove Missing Tracks** | Removes tracks whose files can no longer be found. |
| **Import FMPS Ratings** / **Import POPM Ratings** | Replaces Tauon's ratings with ratings stored in your files' tags. Rescan tags first if they've changed. |
| **Reset User Ratings** | Deletes all ratings. Click once for a warning, then again while holding `Shift`. |
| **Find Incomplete Albums** | Makes a playlist of albums that seem to be missing tracks, judging by track numbers. |
| **Mark Missing as Found** ⇧ | Un-greys tracks that were marked as missing. |

## Playback menu

Click ☰ at the right end of the bottom panel.

| Item | Details |
| --- | --- |
| **Audio Info** | Shows the format, sample rate, channel levels and ReplayGain of the playing track. |
| **Mini Mode** | Switches to a [mini mode](/manual/mini-mode/) style. |
| **Random Track** | Plays a random track from the playing playlist. |
| **Radio Random** | Plays a random track from a random point. |
| **Revert** | Goes back to the previous track and continues where it left off. |
| **Clear Queue** | Empties the [queue](/manual/queue/). |
| **Love** | Loves the playing track. |
| **Global Search** | Opens [search](/manual/search/). |
| **Locate Artist** | Finds the playing artist in the playlist you're viewing. Repeat to find their next album. |
| **Go To Playing** | Shows the playing track. If the same track is in the playlist you're viewing, playback continues from there. |
| Speed slider | Changes the playback speed, from 0.1× to 3×. |

## Playlist tab menu

Right-click a playlist tab.

| Item | Details |
| --- | --- |
| **Rename** | Renames the playlist. |
| **Pin** / **Unpin** | Shows or hides the playlist's tab in the top panel. Unpinned playlists stay in the left panel. |
| **Lock** ⇧ | Protects the playlist from being deleted or sorted. You can still add tracks to it. |
| **Clear** | Removes all tracks from the playlist. |
| **Delete** | Deletes the playlist. Press `Ctrl` + `Z` to undo. |
| **Regenerate** | Updates a [smart playlist](/manual/generators/). |
| **Generate…** | Creates a new smart playlist from this one, using a preset. |
| **Edit Generator…** | Edits this playlist's smart playlist code. |
| **Sort…** | Sorts the playlist in place: by imported tracks or folders, file path, track number, or year per artist. **Restore Sorting** undoes a sort. **Make Playlist Auto-Sorting** keeps it sorted as tracks are added. |
| **Rescan Folder** | Re-imports the folders this playlist was built from. |
| **Paste** | Adds copied tracks to the end of the playlist. |
| **Append Playing** | Adds the playing track to the end of the playlist. |
| **Import/Export…** | [Exports](/manual/playlist-export/) the playlist as XSPF or M3U. |
| **Toggle Grouping** | Shows or hides album headings for this playlist (`F1`). |
| **Misc…** | More options, below. |

**Misc…** contains: **Export Playlist Stats** (a text file of statistics such as playtime per artist), **Export Albums CSV**, **Transcode All**, **Rescan Tags**, **Engage Gallery Quick Add** and **Set as Sync Playlist** (see [Sync](/manual/transcoding/#sync)), **Set as Downloads Playlist** (see [Download Importing](/manual/download-importing/)), and **Remove Duplicates**.

## Track menu

Right-click a track.

| Item | Details |
| --- | --- |
| **Open Folder** | Opens the track's folder in your file manager. |
| **Track Info…** | Shows the track's details. |
| **Love** | Loves or unloves the track. |
| **Add to Queue** | Adds the track to the [queue](/manual/queue/). Middle-clicking the track does the same. |
| **↳ After Current Track** ⇧ | Puts the track at the front of the queue. |
| **Edit Tags…** | Opens the [tag editor](/manual/tag-editor/). |
| **Meta…** | **Rename Tracks…**, **Modify Folder…** (see [Folder Management](/manual/folder-management/)), **Rescan Tags**, **Lyrics…** and **Fix Mojibake** |
| **Copy** / **Paste** | Copies and pastes tracks. |
| **Delete Track File** ⇧ | Moves the track's file to the trash. |
| Search links | Looks up the artist or track on Wikipedia, Genius, Bandcamp or Sonemic. Choose which links appear in the **Layout** submenu. |
| **Transcode Folder** | [Transcodes](/manual/transcoding/) the album. Hold `Shift` to transcode only this track. |
| **Layout** | Tracklist appearance: columns, loves, ratings, font size and row height. |

Right-click an **album heading** for album versions of these, plus **Add Album to Queue**, **Enqueue Album Next**, and **Vacuum Playtimes** ⇧ (see [App Data](/manual/app-data/#recovering-play-counts-for-an-album)).

## Album art menu

Right-click the album art in the side panel.

| Item | Details |
| --- | --- |
| **Open Image** | Opens the image in your image viewer. |
| **Next Image** | Shows another image from the album's folder. |
| **Extract Image** | Saves an embedded image as a file in the album's folder. |
| **Delete Image File** | Deletes the image file. For embedded art, this removes the art from the tracks in the album (MP3, FLAC and M4A). |
| **Quick-Fetch Cover Art** | Searches online for the album's cover art and saves it in the album's folder. Needs artist and album tags. |
| **Use Centered Style** | An alternative side panel layout with centered track details. |
| **Zoom Art to Fit** | Fills the panel with the art, even if it's small. |
| **MilkDrop Visualiser** | Turns on the [MilkDrop visualiser](/manual/milkdrop/). |
