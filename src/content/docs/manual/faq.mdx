**What platforms is Tauon for?**

Tauon's native platform is Linux with cross platform support Windows and macOS.

___

**What is Tauon?**

Tauon is a project started in 2015 with the goal of being the best music player for folder based music libraries.

Its not just features though, Tauon has lots of stylish UI options to make it look awesome.

___

**Is Tauon free?**

Tauon is a free and open source project licensed under the GPLv3. Designed for the sake of music. No ads, no tracking, no paywalls, no bullshit. (Although I say that, if you find yourself using Tauon a lot, I would love it if you would support me on [Patreon](https://www.patreon.com/taiko2k) or [GitHub Sponsors](https://github.com/sponsors/Taiko2k)).

___

**Does Tauon organise my music for me?**

Not exactly. Basically you import all your music into one playlist. From there you can search and create filtered and sorted playlists, and group playlists into [folders](/manual/playlist-folders/).

Tauon's [tag editor](/manual/tag-editor/) can fix your tags, including looking up correct tags on MusicBrainz.

Tauon works best if your music library is structured and properly tagged. At minimum every album should be in its own folder.

___

**Where do I get music from?**

There are many sources for music. [Bandcamp](http://bandcamp.com/) is a great place for indie and alternative music both paid and free.

___

**What audio engine does this app use?**

It uses its own built-in audio processor.

___

**Can this application handle large music collections?**

Tauon is intended to work well with ***medium*** to large music libraries. However, if you have a *huge* number of tracks, you may notice longer load times and degraded UI performance in some elements such as search.

There's no hard limit to the number of tracks you can import, but to give a ballpark number, it should handle at least up to ~50k tracks comfortably.


## Technical FAQs

___

**What toolkit is this program using?**

It's using a custom GPU-accelerated UI written in Python, built upon SDL3.

___

**Can I load music from network folders?**

On Linux, if you can mount the folder, you can access it like any other filesystem. Network folders aren't supported on Windows.

This isn't necessarily the ideal way of doing this, however. It might be better to run a music network server designed specifically for music such as [Jellyfin](https://jellyfin.org/).

___


## Troubleshooting FAQs


**My music isn't detected any more! (Its in `/run` or `/mnt` and I'm using Flatpak)**

Drag and drops to Flatpak applications are only transient, to make them permanent you need to grant file permissions.

You can use the app [Flatseal](https://flathub.org/en/apps/com.github.tchx84.Flatseal) to do this.

___

**I'm using Flatpak with NVIDIA and the window just shows an empty border on launch**

Try run `flatpak update`.


___
**I tried installing/updating the Flatpak but it gives error "Aborted due to failure..."**

Try run: `sudo flatpak repair && flatpak repair --user && flatpak update`

**I added new items to my home music folder, but they didn't then immediately show up in Tauon, why?**

Tauon doesn't have background scanning. Either import the new items yourself, right-click the playlist tab and choose **Rescan Folder**, or choose **Database… › Reload All Folders** from the main menu.

___
**Some of my albums don't have album art!**

Album art is picked up from image files in the album's folder and from images embedded in the tracks. If an album has neither, you can add an image to its folder, embed one with the [tag editor](/manual/tag-editor/), or, while the album is playing, right-click the album art area in the side panel and choose **Quick-Fetch Cover Art**.
___
**Some of the thumbnails in the gallery aren't showing the correct cover image, how to I change it?**

Right-click the thumbnail and choose **Image… › Next**. If you've updated the artwork, choose **Database… › Reset Image Cache** from the main menu.
