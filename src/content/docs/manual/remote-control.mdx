title: Remote Control
description: Control Tauon with media keys, the command line, or over the network
---

## Media keys

Media keys (play/pause, next, previous) work on all platforms:

- **Linux:** through MPRIS2 over D-Bus. GNOME and KDE need no extra setup.
- **Windows:** through the system media controls.
- **macOS:** through Now Playing, including Control Center.

## Command line

### playerctl (Linux)

[playerctl](https://github.com/altdesktop/playerctl) controls Tauon through MPRIS2, including volume and shuffle:

```bash
playerctl -p tauon play
```

### D-Bus (Linux)

If `playerctl` doesn't suit you, send commands over D-Bus directly. For example, to skip to the next track:

```bash
dbus-send --print-reply --session --dest=org.mpris.MediaPlayer2.tauon /org/mpris/MediaPlayer2 org.mpris.MediaPlayer2.Player.Next
```

:::note
Tauon doesn't implement the MPRIS *TrackList* or *Playlists* interfaces.
:::

### Tauon commands

On every platform, you can control a running Tauon by running its executable with a command such as `--pause`, `--next` or `--playpause`, or pass it files to open:

```bash
tauon --pause
tauon ~/Music/MyAlbum/song.mp3
```

See [Command-Line Options](/manual/command-line/) for every command, the executable's path on each platform, and how opening files works.

## Over the network

:::caution[Security]
Network control is not authenticated or encrypted. Only turn it on in a trusted network, and don't expose the port to the internet.
:::

To allow control over the network, turn on **Settings › Connect › Sharing › Enable remote control**, then restart Tauon. This starts an HTTP API on port 7814, used by:

- the [Tauon for iOS](/manual/tauon-for-ios/) app
- [another Tauon](/manual/network-sources/#another-tauon-on-your-network) on your network
- your own scripts. See the [Remote Control API](https://github.com/Taiko2k/Tauon/wiki/Remote-Control-API) wiki page.

### Listen Along

**Settings › Connect › Sharing › Enable Listen Along** starts a web page that lets others hear what you're playing in their browser. Click **Open** next to **Listen Along page** to see it.
