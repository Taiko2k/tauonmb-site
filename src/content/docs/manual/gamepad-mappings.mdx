---
title: Gamepad Mappings
description: Control Tauon with a gamepad
---

A gamepad can be used for basic control of Tauon. Turn it on in **Settings › System › Input and export › Enable gamepad input**, then restart Tauon.

| Button | Action |
| --- | --- |
| `A` | Play the selected track (or play/pause if it's already playing) |
| `B` | Stop, or close an open dialog |
| `Y` | Play/pause |
| `X` | Toggle the gallery with keyboard control |
| `LB` / `RB` | Previous/next track |
| `D-pad Up` / `Down` | Move the selection |
| `D-pad Left` / `Right` | Switch playlists (move between albums in the gallery) |
| Left stick up/down | Scroll quickly |
| Right stick left/right | Seek |
| Right stick up/down | Volume |

With **LT** held:

| Button | Action |
| --- | --- |
| `A` | Show the playing track |
| `B` | Revert to the previous track |
| `X` | Random track |
| `Y` | Random track, starting at a random point |
| `LB` | Toggle repeat |
| `RB` | Toggle shuffle |
